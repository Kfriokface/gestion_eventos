# Gestión de eventos con Node
Aplicación básica en **Node.js + Express + EJS** que crea un flujo que permite registrarse a un evento.

---

## Objetivos del ejercicio

- Mostrar un formulario para registrar un evento.
- Validar los datos en el servidor.
- Mostrar una página de confirmación (evento-ok.ejs) con los resultados.

---

## Tecnologías utilizadas

| Tecnología                               | Descripción          |
| ---------------------------------------- | -------------------- |
| [Node.js](https://nodejs.org/)           | Entorno de ejecución |
| [Express](https://expressjs.com/)        | Framework backend    |
| [EJS](https://ejs.co/)                   | Motor de plantillas  |
| [Bootstrap 5](https://getbootstrap.com/) | Estilos y diseño     |

---

## Instalación y puesta en marcha

1. Clonar el repositorio o copiar los archivos:
   ```bash
   git clone https://github.com/Kfriokface/gestion_eventos.git
   cd gestion_eventos
   npm install
   ```
2. Arrancar server
   ```bash
   npm run start
   ```
3. Navegar a http://localhost:3000
